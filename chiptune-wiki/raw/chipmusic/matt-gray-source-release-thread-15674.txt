Fancy composing Commodore 64 music old school style? Matt Gray, author of Last Ninja 2, Driller, and more has released the original 6502 source code to one of his tunes "Dominator Subtune 6" on Creative Commons for C64 SID composers to learn from and play with.
There's also a composition competition with a deadline of next March to be released in 2015 as part of his Reformation Kickstarter at http://goo.gl/fSsE3J
If you wondered how composers such as Matt, Rob Hubbard, Fred Gray, etc, did their original tunes, then this will give you some good insight.
The ZIP file contains the source code (with tune data), and a compatible cross-assembler.
URL: http://www.remix64.com/articles/matt-gr … ition.html
For more details on Matt's Remake CD project which now includes him doing 6 new SIDs (and which closes 2nd December, when the Last Ninja 2 CD and vinyl will go away), check it out, but quickly.
