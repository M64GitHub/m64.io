Melody Lab

Generates melodies from the current scale on a 16th-note grid, tracker-style. Click a note to reroll it · double-click to mute it to a rest. ··· = rest, | = note still ringing · 3xx = slide into the note (tone portamento) · the Bass column shows the octave-bass figure playing underneath (display only, no fx). The IT / SWM buttons in the column headers copy that column to the clipboard for DUET, OpenMPT or Schism.
