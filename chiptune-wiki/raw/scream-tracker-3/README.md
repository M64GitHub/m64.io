# Scream Tracker 3 documentation (provenance note)

- `ST3-manual.txt` — "Scream Tracker 3.2 — User's Manual", (C) 1994 Kalle Kaivola (Edge / Electromotive Force), the ST3.DOC of the Scream Tracker 3.2x distribution; fetched 2026-08-30 from http://www.textfiles.com/computers/DOCUMENTATION/st3.txt (CP437 text, 1262 lines). `ST3-manual-utf8.txt` is the same file converted CP437 → UTF-8 for the viewer.
- `TECH.DOC` — "Scream Tracker 3.20 File Formats And Mixing Info", the official S3M format description from the ST 3.20/3.21 distribution (Sami Tammilehto / Future Crew); fetched 2026-08-30 from https://raw.githubusercontent.com/reznet/S3MParser/master/TECH.DOC (CP437, 402 lines). `TECH-utf8.txt` is the UTF-8 conversion.
- An OCR'd copy of the manual also exists at https://archive.org/details/ScreamTracker3UsersManual (not used).

Scream Tracker 3 was distributed as freeware ("you have the right to use the program but not sell it", manual §1.3).
